WELLEN ENTDECKEN – WEBAPP FÜR LOUIS

INHALT
- index.html: die eigentliche Lern-Webseite
- manifest.webmanifest: macht die Seite auf dem Handy app-ähnlich
- sw.js: ermöglicht nach dem ersten Laden auch Offline-Nutzung

SCHNELLSTE VERÖFFENTLICHUNG MIT GITHUB PAGES
1. Auf github.com anmelden oder kostenlos registrieren.
2. Oben rechts auf + -> New repository.
3. Repository-Name z.B. wellen-louis.
4. Public auswählen und Create repository.
5. Im neuen Repository: Add file -> Upload files.
6. index.html, manifest.webmanifest und sw.js hochladen.
7. Commit changes anklicken.
8. Settings -> Pages.
9. Unter Build and deployment bei Source: Deploy from a branch.
10. Branch: main, Ordner: /(root), dann Save.
11. Nach kurzer Zeit erscheint dort die Webadresse.

IPHONE / IPAD
- Link in Safari öffnen.
- Für Ton einmal auf "Ton anhören" tippen. Das ist bei iOS erforderlich.
- Optional: Teilen-Symbol -> Zum Home-Bildschirm. Danach wirkt die Seite wie eine kleine App.
- Nach dem ersten vollständigen Laden funktioniert sie in der Regel auch ohne Internet.

WICHTIG
Die Seite sammelt keine Daten und verwendet keine externen Dienste.
